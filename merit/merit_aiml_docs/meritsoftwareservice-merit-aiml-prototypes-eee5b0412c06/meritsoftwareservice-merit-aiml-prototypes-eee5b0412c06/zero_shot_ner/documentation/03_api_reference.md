## Overview

The Zero-Shot NER API provides RESTful endpoints for entity extraction and relation identification. The API is built with Flask and supports JSON-based communication with HTTP Basic Authentication.

### API Characteristics

- **Protocol**: HTTP/HTTPS
- **Data Format**: JSON
- **Authentication**: HTTP Basic Auth
- **Default Port**: 5000 (configurable)
- **Base URL**: `http://localhost:5000`

### API Lifecycle

The API server includes automatic lifecycle management:
- **Auto-Start**: Launched automatically by the Streamlit interface when needed
- **Health Monitoring**: Background thread tracks request activity
- **Auto-Shutdown**: Server terminates after configured inactivity period (default: 5 hours)

## Base Configuration

### Configuration File (`config.ini`)

```ini
[api]
port = 5000              # API server port
ip = localhost           # API server host
flask_start_cmd = python api/model_api.py
time_delta = 5           # Hours of inactivity before shutdown
device = cpu             # cpu or cuda
usr = zero_shot          # API username
pwd = P@ssw0rd           # API password
both_models = False      # Enable both GLiNER and NuNER models
```

### Server Startup

**Manual Startup**:
```bash
python api/model_api.py
```

**Automatic Startup**:
The Streamlit interface automatically starts the API if it's not running when a request is made.

### Health Check

Before the API accepts requests, it loads the configured models. Initial startup may take 30-60 seconds for model loading.

### 2. Named Entity Recognition

**Endpoint**: `POST /ner`

**Description**: Extracts named entities from text using user-defined labels.

**Authentication**: Required (HTTP Basic Auth)

**Request Body**:

| Field | Type | Required | Default | Description |
|-------|------|----------|---------|-------------|
| `model` | string | Yes | - | Model name: "gliner" or "numind" |
| `input_text` | string | Yes | - | Text to analyze (min 10 chars) |
| `labels` | array | Yes | - | List of entity labels (each min 3 chars) |
| `threshold` | float | No | 0.5 | Confidence threshold (0.0-1.0) |
| `nested_ner` | boolean | No | false | Allow nested entity recognition |

**Request Schema**:
```json
{
  "model": "gliner",
  "input_text": "Apple Inc. is headquartered in Cupertino, California.",
  "labels": ["organization", "location"],
  "threshold": 0.5,
  "nested_ner": false
}
```

**Response**:

**Success (200 OK)**:
```json
{
  "render_data": "<div class=\"entities\" style=\"line-height: 2.5; direction: ltr\">...</div>"
}
```

The `render_data` field contains HTML generated by spaCy's displacy visualizer with color-coded entities.

**Error (400 Bad Request)**:
```json
{
  "error": "Invalid model name: invalid_model"
}
```

**Validation Rules**:
- `model` must be "gliner" or "numind"
- `input_text` must be at least 10 characters
- Each label in `labels` must be at least 3 characters
- `threshold` must be between 0.0 and 1.0
- If `both_models` is False in config, only "gliner" is available

**Example Request**:
```python
import requests
from requests.auth import HTTPBasicAuth

url = "http://localhost:5000/ner"
data = {
    "model": "gliner",
    "input_text": "John Smith works at Microsoft in Seattle.",
    "labels": ["person", "organization", "location"],
    "threshold": 0.5,
    "nested_ner": False
}

response = requests.post(
    url,
    json=data,
    auth=HTTPBasicAuth('zero_shot', 'P@ssw0rd')
)

if response.status_code == 200:
    html_output = response.json()['render_data']
    print(html_output)
else:
    print(f"Error: {response.json()['error']}")
```

**Example Response** (HTML excerpt):
```html

        John Smith
        <span style="font-size: 0.8em; font-weight: bold; line-height: 1; border-radius: 0.35em; vertical-align: middle; margin-left: 0.5rem">person (95.23%)</span>
```

### 3. Relation Extraction

**Endpoint**: `POST /relation`

**Description**: Extracts relationships between entities in text based on user-defined relation types and entity label pairs.

**Authentication**: Required (HTTP Basic Auth)

**Request Body**:

| Field | Type | Required | Default | Description |
|-------|------|----------|---------|-------------|
| `input_text` | string | Yes | - | Text to analyze (min 30 chars) |
| `labels` | array | Yes | - | List of entity labels (each min 3 chars) |
| `relation` | string | Yes | - | Relation name (min 3 chars) |
| `pairs` | string | Yes | - | Comma-separated pairs (e.g., "person -> organization") |
| `threshold` | string | No | "" | Distance threshold in characters (optional) |

**Request Schema**:
```json
{
  "input_text": "John Smith works at Microsoft. The company is based in Seattle.",
  "labels": ["person", "organization", "location"],
  "relation": "works_for",
  "pairs": "person -> organization",
  "threshold": ""
}
```

**Response**:

**Success (200 OK)**:
```json
{
  "relations": [
    {
      "head": {
        "text": "John Smith",
        "label": "person",
        "start": 0,
        "end": 10,
        "score": 0.95
      },
      "tail": {
        "text": "Microsoft",
        "label": "organization",
        "start": 20,
        "end": 29,
        "score": 0.97
      },
      "relation": "works_for",
      "score": 0.89
    }
  ]
}
```

**Error (400 Bad Request)**:
```json
{
  "error": "Invalid labels (req. min 3 chars): ['ab', 'x']"
}
```

**Validation Rules**:
- `input_text` must be at least 30 characters
- Each label in `labels` must be at least 3 characters
- `relation` must be at least 3 characters
- `pairs` must be at least 7 characters (format: "x -> y")
- `threshold` is optional; if provided, must be a numeric string

**Pairs Format**:
The `pairs` field specifies which entity types can participate in the relation:
- Single pair: `"person -> organization"`
- Multiple pairs: `"person -> organization, organization -> location"`
- Format: `"source_label -> target_label"`

**Distance Threshold**:
Optional character-based distance limit between entities:
- Empty string or omitted: No distance constraint
- Numeric string (e.g., "100"): Maximum 100 characters between entity spans

**Example Request**:
```python
import requests
from requests.auth import HTTPBasicAuth

url = "http://localhost:5000/relation"
data = {
    "input_text": "Dr. Sarah Johnson works as a researcher at Stanford University in California.",
    "labels": ["person", "organization", "location"],
    "relation": "employed_by",
    "pairs": "person -> organization",
    "threshold": ""
}

response = requests.post(
    url,
    json=data,
    auth=HTTPBasicAuth('zero_shot', 'P@ssw0rd')
)

if response.status_code == 200:
    relations = response.json()['relations']
    for rel in relations:
        print(f"{rel['head']['text']} --[{rel['relation']}]--> {rel['tail']['text']}")
        print(f"Confidence: {rel['score']:.2%}")
else:
    print(f"Error: {response.json()['error']}")
```

**Example Response**:
```json
{
  "relations": [
    {
      "head": {
        "text": "Dr. Sarah Johnson",
        "label": "person",
        "start": 0,
        "end": 17,
        "score": 0.94
      },
      "tail": {
        "text": "Stanford University",
        "label": "organization",
        "start": 42,
        "end": 61,
        "score": 0.96
      },
      "relation": "employed_by",
      "score": 0.91
    }
  ]
}
```

| Status Code | Meaning | When Used |
|-------------|---------|-----------|

| 404 | Not Found | Invalid endpoint |

## Error Handling

### Error Response Format

All errors return JSON with an `error` field:

```json
{
  "error": "Error description"
}
```

### Common Errors

#### 1. Authentication Errors

**Error**: Missing credentials
```
Status: 401 Unauthorized
Body: "Unauthorized Access"
```

**Error**: Invalid credentials
```
Status: 401 Unauthorized
Body: "Unauthorized Access"
```

#### 2. Validation Errors

**Error**: Invalid model name
```json
{
  "error": "Invalid model name: unknown_model"
}
```

**Error**: Text too short
```json
{
  "error": "ensure this value has at least 10 characters"
}
```

**Error**: Invalid labels
```json
{
  "error": "Invalid labels (req. min 3 chars): ['ab', 'x']"
}
```

#### 3. Processing Errors

**Error**: Model not loaded
```
Status: 500 Internal Server Error
```

### Error Handling Best Practices

```python
import requests
from requests.auth import HTTPBasicAuth
from requests.exceptions import RequestException

def call_ner_api(text, labels, model="gliner"):
    url = "http://localhost:5000/ner"
    data = {
        "model": model,
        "input_text": text,
        "labels": labels,
        "threshold": 0.5,
        "nested_ner": False
    }

    try:
        response = requests.post(
            url,
            json=data,
            auth=HTTPBasicAuth('zero_shot', 'P@ssw0rd'),
            timeout=30
        )

        if response.status_code == 200:
            return response.json()['render_data']
        elif response.status_code == 400:
            print(f"Validation Error: {response.json()['error']}")
            return None
        elif response.status_code == 401:
            print("Authentication failed. Check credentials.")
            return None
        else:
            print(f"Unexpected error: {response.status_code}")
            return None

    except RequestException as e:
        print(f"Request failed: {e}")
        return None
```

## Code Examples

### Python Client Class

```python
import requests
from requests.auth import HTTPBasicAuth
from typing import List, Dict, Optional

class ZeroShotNERClient:
    def __init__(self, base_url: str = "http://localhost:5000",
                 username: str = "zero_shot",
                 password: str = "P@ssw0rd"):
        self.base_url = base_url
        self.auth = HTTPBasicAuth(username, password)

    def health_check(self) -> bool:
        """Check if API is available."""
        try:
            response = requests.get(f"{self.base_url}/")
            return response.status_code == 200
        except requests.RequestException:
            return False

    def extract_entities(self,
                        text: str,
                        labels: List[str],
                        model: str = "gliner",
                        threshold: float = 0.5,
                        nested_ner: bool = False) -> Optional[str]:
        """
        Extract entities from text.

        Args:
            text: Input text to analyze
            labels: List of entity labels to extract
            model: Model name ("gliner" or "numind")
            threshold: Confidence threshold (0.0-1.0)
            nested_ner: Allow nested entities

        Returns:
            HTML rendering of entities or None on error
        """
        url = f"{self.base_url}/ner"
        data = {
            "model": model,
            "input_text": text,
            "labels": labels,
            "threshold": threshold,
            "nested_ner": nested_ner
        }

        try:
            response = requests.post(url, json=data, auth=self.auth, timeout=30)
            if response.status_code == 200:
                return response.json()['render_data']
            else:
                print(f"Error: {response.json().get('error', 'Unknown error')}")
                return None
        except requests.RequestException as e:
            print(f"Request failed: {e}")
            return None

    def extract_relations(self,
                         text: str,
                         labels: List[str],
                         relation: str,
                         pairs: str,
                         threshold: str = "") -> Optional[List[Dict]]:
        """
        Extract relations between entities.

        Args:
            text: Input text to analyze
            labels: List of entity labels
            relation: Relation name to extract
            pairs: Entity pair filter (e.g., "person -> organization")
            threshold: Optional distance threshold

        Returns:
            List of extracted relations or None on error
        """
        url = f"{self.base_url}/relation"
        data = {
            "input_text": text,
            "labels": labels,
            "relation": relation,
            "pairs": pairs,
            "threshold": threshold
        }

        try:
            response = requests.post(url, json=data, auth=self.auth, timeout=30)
            if response.status_code == 200:
                return response.json()['relations']
            else:
                print(f"Error: {response.json().get('error', 'Unknown error')}")
                return None
        except requests.RequestException as e:
            print(f"Request failed: {e}")
            return None

# Usage example
if __name__ == "__main__":
    client = ZeroShotNERClient()

    # Check API health
    if not client.health_check():
        print("API is not available")
        exit(1)

    # Extract entities
    text = "Apple Inc. announced new products. Tim Cook spoke at the event in Cupertino."
    labels = ["organization", "person", "location", "product"]

    html = client.extract_entities(text, labels)
    if html:
        print("Entities extracted successfully")
        # Save HTML to file or display in web page
        with open("output.html", "w") as f:
            f.write(html)

    # Extract relations
    relations = client.extract_relations(
        text=text,
        labels=["person", "organization"],
        relation="works_for",
        pairs="person -> organization"
    )

    if relations:
        for rel in relations:
            print(f"{rel['head']['text']} --[{rel['relation']}]--> {rel['tail']['text']}")
```

### JavaScript/Node.js Example

```javascript
const axios = require('axios');

class ZeroShotNERClient {
    constructor(baseUrl = 'http://localhost:5000', username = 'zero_shot', password = 'P@ssw0rd') {
        this.baseUrl = baseUrl;
        this.auth = {
            username: username,
            password: password
        };
    }

    async healthCheck() {
        try {
            const response = await axios.get(`${this.baseUrl}/`);
            return response.status === 200;
        } catch (error) {
            return false;
        }
    }

    async extractEntities(text, labels, model = 'gliner', threshold = 0.5, nestedNer = false) {
        const url = `${this.baseUrl}/ner`;
        const data = {
            model: model,
            input_text: text,
            labels: labels,
            threshold: threshold,
            nested_ner: nestedNer
        };

        try {
            const response = await axios.post(url, data, {
                auth: this.auth,
                timeout: 30000
            });
            return response.data.render_data;
        } catch (error) {
            console.error('Error:', error.response?.data?.error || error.message);
            return null;
        }
    }

    async extractRelations(text, labels, relation, pairs, threshold = '') {
        const url = `${this.baseUrl}/relation`;
        const data = {
            input_text: text,
            labels: labels,
            relation: relation,
            pairs: pairs,
            threshold: threshold
        };

        try {
            const response = await axios.post(url, data, {
                auth: this.auth,
                timeout: 30000
            });
            return response.data.relations;
        } catch (error) {
            console.error('Error:', error.response?.data?.error || error.message);
            return null;
        }
    }
}

// Usage
(async () => {
    const client = new ZeroShotNERClient();

    const text = "Microsoft was founded by Bill Gates in Seattle.";
    const labels = ["organization", "person", "location"];

    const html = await client.extractEntities(text, labels);
    console.log('Entity HTML:', html);

    const relations = await client.extractRelations(
        text,
        ["person", "organization"],
        "founded",
        "person -> organization"
    );
    console.log('Relations:', relations);
})();
```

## Client Libraries

### Official Client (Python)

The prototype includes a built-in client in `interface/inference.py`:

```python
from interface.inference import Inference
from utils import Utils

class Client(Utils, Inference):
    def __init__(self):
        super().__init__()
        self.config_data = self.read_config()

    def extract(self, text, labels):
        return self.get_ner_output("gliner", self.config_data, text, labels)
```
