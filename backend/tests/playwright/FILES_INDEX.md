## How Files Are Used

### Test Execution Flow

1. **RUN_TESTS.sh** → Checks services → Runs pytest
2. **pytest** → Loads `conftest.py` (fixtures)
3. **conftest.py** → Sets up Playwright, browser, login
4. **Test files** → Use page objects to interact with UI
5. **Page objects** → Provide methods for UI interactions
6. **test_reporter.py** → Captures screenshots and generates reports
7. **test_results/** → Stores all screenshots and reports

### Documentation Hierarchy

1. **TESTING_COMPLETE_SUMMARY.md** (root) - Quick overview
