# INSTALLATION NOTES

# QUICK START (Minimal Install):
#   pip install -r requirements.txt
#   This installs core functionality without heavy ML packages
#

#   1. Uncomment torch, transformers, vllm lines in "AI & LLM" section
#   2. pip install -r requirements.txt
#   Note: This adds ~3GB of downloads
#
# RAG EVALUATION INSTALL:
#   The evaluation packages are now included by default but have dependencies:
#   - ragas, deepeval, rouge-score, nltk, fairlearn: Work without torch
#   - bert-score, detoxify: REQUIRE torch and transformers
#
#   To use ALL evaluation features:
#   1. Uncomment torch, transformers lines in "AI & LLM" section
#   2. pip install -r requirements.txt
#
#   WARNING about deepeval:
#   - Requires protobuf==4.25.1 (specific version)
#   - May conflict if other packages need different protobuf versions
#   - Monitor for dependency resolution conflicts during install
#
# OPTIONAL FEATURES:
#   - LangChain/LangGraph: Already included for agent workflows
#   - Prefect: Already included for workflow orchestration
#   - Docling: Install separately if available: pip install docling
#

#   After pip install, run: playwright install chromium
