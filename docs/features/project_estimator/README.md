## 🔑 Key Concepts to Understand

### Formula Preservation
- All calculations must be Excel formulas, not hard-coded values
- Reference: Estimation_Logic_Quick_Reference.md

### Cross-Sheet References
- 5 tabs with interconnected VLOOKUP and SUM formulas
- Reference: Claude_Code_Project_Estimator_Prompt.md (Excel structure)

### Auto-Calculated Overhead
- SA, PM, BA, Testing, Contingency must auto-calculate
- Reference: Estimation_Logic_Quick_Reference.md (formulas)

### AI Analysis Integration
- Claude API analyzes scope and extracts structured data
- Reference: Implementation_Code_Examples.md (Claude API section)
